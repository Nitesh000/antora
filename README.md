# Antora UI

**Antora** is a production-grade React UI library built on top of the shadcn v4 architecture. It brings together **Material 3 Expressive** design principles—bold, opaque, high-contrast aesthetics with no frosted glass—and **Native Fluidity**, utilizing Framer Motion's FLIP engine to deliver realistic squash-and-stretch physics, micro-springs, and neighbor-aware momentum.

![hero](apps/v4/public/opengraph-image.png)

## Core Philosophy

1. **Material 3 Expressive Design:** Unapologetically bold color scales, stark contrasts, and opaque surfaces.
2. **iOS-Level Physics:** CSS transitions are fundamentally insufficient for structural layout shifts. Antora uses deep Framer Motion integrations to give every layout shift physical mass, so expanding components physically push their neighbors smoothly.
3. **Interactive Micro-Springs:** `whileTap` springs simulate realistic finger pressure across buttons, inputs, and toggles.
